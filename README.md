# QuizMaster AI – AI-Based Smart Quiz Generation and Assessment System

## 📌 Project Overview

QuizMaster AI is an AI-powered web application that automatically generates quizzes from study materials such as PDFs, notes, textbooks, and plain text. It helps students and teachers save time by creating quizzes quickly using Artificial Intelligence.

The system provides instant feedback, evaluates answers, tracks student performance, and identifies weak areas to improve the learning experience.

## 🎯 Objectives

- Automatically generate quiz questions using AI.
- Save students' and teachers' time.
- Provide instant feedback and evaluation.
- Generate quizzes with different difficulty levels.
- Track students' performance and progress.
- Identify weak areas and improve learning.

## ✨ Key Features

### 👨‍💼 Admin
- Login and Logout
- Manage Teacher Accounts
- Manage Student Accounts
- Manage Courses and Subjects
- Monitor Generated Quizzes
- Monitor Platform Activities
- Activate or Deactivate User Accounts

### 👩‍🏫 Teacher
- Upload Learning Materials
- Generate AI-Based Quizzes
- Select Difficulty Levels (Easy, Medium, Hard)
- Choose Question Types (MCQ, True/False, Short Answer, Mixed)
- Set the Number of Questions
- Share Quizzes with Students
- View Student Scores and Performance Reports

### 👨‍🎓 Student
- Upload Notes or Paste Study Content
- Generate Personalized Quizzes
- Select Difficulty Levels and Question Types
- Attempt Quizzes with Progress Tracking
- Receive Instant Feedback
- View Scores, Grades, and Results
- Review Correct Answers and Explanations
- Retake Existing Quizzes or Generate New Ones

### 🤖 AI Features
- **AI Quiz Generator:** Automatically generates questions from study materials.
- **AI Answer Evaluator:** Evaluates short answers based on their meaning.
- **AI Explanation Generator:** Provides explanations for correct answers.
- **AI Note Summarizer:** Summarizes lengthy study materials before quiz generation.
